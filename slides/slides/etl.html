Task 1a: an ETL that can run twice

--initial

Full history since 1999. Delete and insert in one transaction: if anything fails, the old data stays.

--daily

From last date minus 5 days, upsert on the date. A second run adds 0 rows, ECB corrections are picked up.

Quality checks

Stop: invalid date or value, rate ≤ 0, duplicates. Warn: missing weekdays that are not TARGET holidays, moves above 5%.

Operations

Timeout, 3 retries, exit code 1 on failure. Load log per run. Scheduled weekdays 16:30 CET, after ECB publication.

Found on real data: until 2012 the ECB sends holidays as empty rows (status H). The hard check stopped the first load; the adapter now drops them. 7,130 days loaded, all checks OK.
